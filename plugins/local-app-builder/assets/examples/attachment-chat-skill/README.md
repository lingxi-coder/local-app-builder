# Attachment Review Chat

A dependency-free schema-2 Local App example for durable App Chats, binary `File` attachments and a packaged runtime Skill. Copy the directory into a project and publish it with `LocalApp({"bundle_path":"/absolute/copied/project"})`. Configure an App model in the trusted Apps UI before using Agent features.

The example stores the selected Chat ID in revision-scoped browser storage and reopens it through `chats.open`. It keeps an in-flight draft and its `File` objects in IndexedDB before calling `chat.send`; after refresh, it shows a Retry button and never sends from startup. That app-owned draft expires after 24 hours and is deleted on expiry or a definitive host rejection. Retries keep the same `requestId`, Chat ID, prompt and files while the draft remains. History and message identities belong to the durable host Chat. The review Skill is an immutable instruction file; it grants no tools, and this example declares none.

The browser SDK sends file bytes and metadata in one bounded multipart request: at most eight files, 25 MiB each and 50 MiB total. Its own request ledger retains pending data for at most 24 hours and accepted idempotency receipts for 7 days, with 32-record/100 MiB caps. It owns the iOS wake-and-return handshake. The SDK also registers a same-origin recovery service worker when supported; that worker caches only its fixed recovery page, never app pages or Agent requests/results. The recovery page lists saved request IDs without revealing prompt text or files, explains expiry, and offers explicit links back to LingXi. If service workers are unavailable, the SDK emits `localApp:recovery-unavailable` and the page reports the limitation.

Mobile Local Apps use the actual system-selected external browser. The example feature-detects APIs and does not branch on browser brand. It contains no provider calls or keys; the native host owns model selection, permissions, execution and the Chat transcript. Source tests and browser previews do not replace device lifecycle or live-model acceptance.
